# 7CODE Releases

Official Windows downloads, signed update information, and website for 7CODE. The application source code is kept separately in a private repository.

**Website:** https://app.7code.workers.dev/

**Windows downloads:** https://github.com/7codemcp/7CODE-Releases/releases/latest

**Updater feed:** https://7code-app.7code.workers.dev/latest.json

7CODE uses Tauri updater signatures to authenticate in-app updates. The private signing key is never stored in this repository. The Tauri signature does not constitute a Windows Authenticode certificate.
